# 快乐英语 App 真机验收清单

版本：2026-11-18 构建（app-debug.apk）
用途：本轮改动全部落在运行期行为上，静态检查覆盖不到，必须真机走一遍。
用法：按顺序执行，每项填「通过 / 不通过 / 备注」，不通过的附现象截图或文字描述。

---

## 0. 前置

| 项 | 操作 |
|---|---|
| 安装 | 直接点击 APK 安装；或 `adb install -r app-debug.apk` |
| 清数据 | 设置 → 应用 → 快乐英语 → 存储 → 清除数据（保证从首次使用状态开始） |
| 网络 | 全程可断网（音频图片都是本地资源，断网也能验） |
| 设备 | 建议用孩子实际用的那台，小屏手机优先（布局最容易挤） |

## 2. 核心链路（这是这 App 的全部价值，逐条验）

### 2.1 点读

| # | 步骤 | 通过标准 |
|---|---|---|
| 2.2.1 | 进 book1 Unit 1，点第一句 | 发音立即播放，图片正常显示 |
| 2.2.2 | 连续点 5 句，每句间隔 1 秒 | 每次都能切换播放，**不串音**（不会上一句还在响） |
| 2.2.3 | 点单词卡片 | 播放单词发音，图片正常 |

### 2.2 跟读打分

| # | 步骤 | 通过标准 |
|---|---|---|
| 2.3.1 | 首次进跟读页 | 弹出麦克风权限，允许后正常进入 |
| 2.3.2 | 点录音，清晰读出句子 | 出分（分数 0–100），星级显示合理（读准≥3 星） |
| 2.3.3 | 故意读错/乱说 | 分数明显偏低，**不出现永远 100 分** |
| 2.3.4 | 点「听示范」 | 播放标准音，与自己的录音可区分 |
| 2.3.5 | 连续跟读 5 句 | 每句都能独立出分，历史分数不互相覆盖 |

### 2.3 慢速（本轮改动重点）

| # | 步骤 | 通过标准 |
|---|---|---|
| 2.4.1 | 跟读页切到「慢速」，点听示范 | 明显变慢，且**音调不变**（不是压扁的那种怪声） |
| 2.4.2 | 保持在慢速，切到下一句 | 仍是慢速（开关状态跨句保留） |
| 2.4.3 | 退出跟读页，回到点读页点句子 | **恢复常速**（本轮修的就是这个跨页串味，若还是慢速即不通过） |
| 2.4.4 | 进单词卡片点词 | 常速 |

## 3. 健壮性（本轮新增兜底，尽量制造异常）

| # | 步骤 | 通过标准 |
|---|---|---|
| 3.1 | 快速连点「听示范」10 次 | 不崩溃、不卡死，最多提示一次播放失败 |
